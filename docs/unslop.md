# 志愿分析工作台界面打磨

设计方向：招生参考册。沿用项目已有的纸白底色、墨色文字和深青强调色，让位次分布与历史投档趋势承担主要视觉信息。

本次按 [unslop](https://github.com/heydamir/unslop) 的轻度问题打磨流程实施。技能作者为 Damir Sokolovsky（[@heydamir](https://x.com/heydamir)），许可为 CC BY 4.0。

## 九轮调整

1. **间距**：首页侧栏统一 24px 内边距、24px 栏间距；主要查询控件统一 48px；手机对比和隐藏操作提供 44px 点击高度。
2. **颜色**：移除页面网格、首页跨色相渐变及浮动对比按钮的彩色光晕。保留已有纸白与深青，风险分组的颜色用于标识，卡片主体保持中性。
3. **图标**：常用操作图标以 16px、1.5 描边为主，风险提示保留 18px；减少标题前的装饰图标，导航选中态改为浅灰表面。
4. **文案**：用历史最低位次余量替代“录取概率很高”等表述；“未录取”改为“低于历史线”；图表趋势明确与最早可用年份比较。位次图不再把数据范围位置写成考生百分位。
5. **字体**：保留现有字体，首页标题桌面 40px、手机 32px；常规字重 400–500，品牌字标保留 600；数据展示使用等宽数字，统一数量的千位分隔。
6. **布局**：保留区块顺序和查询流程；手机各年指标改为三列，较宽屏幕六列；中英文导航在空间不足时折叠。
7. **细节**：辅助文字提升至至少 12px；补全查询标签、导航选中语义和展开状态；隐藏输入区域退出可访问视图，避免重复的表单控件。
8. **视觉**：保留真实位次分布和多序列趋势图；淡化图表网格，突出第一条趋势线；图例和摘要使用安静的中性表面。未生成图片，未使用图片提示词。
9. **动效**：展开收起不再动画化 height、margin、padding 和 left；短反馈主要使用透明度和位移；统一缓动，并响应减少动态效果设置。

## 验证

- 按仓库 `package-lock.json` 执行 `npm ci`，使用 Next.js 14.2.30 构建；8 个静态页面生成成功。
- `npx tsc --noEmit` 通过；修改过的 TypeScript/React 文件使用 `next/core-web-vitals` 规则检查，0 个错误。保留的院校 SVG `<img>` 有 1 条已有类型的优化建议。
- 生产静态预览保留 `/Shanghai-Gaokao/` 资源前缀。
- 位次 5,000、2025 年：1,451 个可选专业组；安全 1,422、稳妥 10、冲刺 19，与改版前一致。
- 验证年份切换、首页带筛选条件跳转、院校搜索、院校与专业组加入对比篮、院校移除后重新添加。
- 验证隐藏专业组后图表移除相应数据，键盘恢复后趋势线重新出现，以及切换到专业组分析。
- 检查中文首页、英文院校库在 320、390、768、1024、1440px 的页面宽度，均无横向溢出；390px 专业组数据卡片无小于 12px 的可见辅助文字。
- 确认英文切换会更新文档语言，减少动态效果媒体设置可生效。

## 范围

改动集中在公共样式与导航、首页、查询、院校库及活跃的图表和表格组件。保留原始 JSON 数据、分层阈值与对比篮存储逻辑；录取规则页沿用已有的交互教学结构。

README 的数据范围同步为实际数据包含的 2020–2025 年。未升级项目依赖；安装工具报告的既有依赖问题需另行维护。
